Quick Start

# 1. Clone & enter the project
git clone https://github.com/NaveenDanj/nuam-detection-engine-python
cd IDS-engine

# 2. Create and activate a virtual environment
python -m venv venv
.\venv\Scripts\Activate.ps1       # Windows
# source venv/bin/activate        # Linux / macOS

# 3. Install dependencies
pip install -r requirements.txt

# 4. Configure (edit .env) then run as Administrator / root
python start_detection.py

⚠ Packet sniffing requires administrator / root privileges.

About

Project Description

LAN Engine runs as a background Python process on a host with LAN access. It uses Scapy to capture raw packets and routes each through a detection pipeline that classifies protocol types, extracts device metadata, and maintains a stateful map of known devices.

🔍

Problem Statement

In modern LAN environments, manually tracking devices leads to incomplete network visibility, delayed threat detection, and poor operational awareness.

🛡️

Solution

Passive, zero-disruption packet sniffing with nine protocol detectors, OUI-based vendor fingerprinting, and real-time WebSocket streaming to enable continuous LAN visibility.

👥

Target Users

Network administrators, security professionals conducting audits, and researchers analysing device behaviour in controlled lab environments.

Objectives

  • ✓ Passively detect all devices active on a LAN without injecting disruptive traffic.
  • ✓ Identify devices using 9 protocol-based detection methods: ARP, DHCP, DNS, ICMP, IP, TCP-IP, SMB, TLS, UDP.
  • ✓ Fingerprint devices by matching MAC OUI prefixes to known vendors.
  • ✓ Track device lifecycle transitions: joined → idle → left.
  • ✓ Stream structured, sequenced events to a backend service in real time.
  • ✓ Provide periodic topology and metric snapshots for dashboards and audits.

Usage

Usage Instructions

Two entry points are available — choose based on your workflow.

Option 1 Direct — Recommended 
python start_detection.py

Starts the detection engine, WebSocket logger, and all periodic tasks in-process.

Option 2 Launcher 
python main.py

Spawns start_detection.py as a subprocess — useful for diagnosing subprocess-level errors.

Example Event Output

When a new device is detected, a DEVICE_JOINED event is streamed to the backend (or written to logs.txt if offline):
